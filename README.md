# 🎬 Movie Explorer

A responsive Movie Explorer web application built with React, TypeScript, and Tailwind CSS. Browse trending shows, search by title, and view detailed information in an interactive modal.

## 🚀 Live Demo

[Live Link](https://movie-explorer-psi-dusky.vercel.app/movies) 

##  Tech Stack

- React + TypeScript
- Tailwind CSS
- React Router
- [TVMaze API](https://www.tvmaze.com/api)

##  Features

- Home page with hero banner and CTA
- Movie listing page with live search
- Responsive movie grid (cards with poster, title, rating, year)
- Movie details modal with overview, genre, rating, and release date
- Fully responsive design (mobile & desktop)

##  Getting Started

bash
git clone <https://github.com/ayeshasiddika3288-ayesha/movie-explorer?utm_source=chatgpt.com>
cd movie-explorer
npm install
npm run dev
